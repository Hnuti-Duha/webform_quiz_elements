### About this module

Create a simple quiz out of a webform with webform quiz elements module.

## New quiz elements

# Quiz radios
Radio buttons have a new property "quiz_options" which indicates which options is correct and to provide a feedback on the selected answer.

# Result element
Rendered element displays result for a specific quiz radio answer.

# Score element
Rendered element displays score for the quiz.

## New token
New token `[webform:quiz_elements_count]` is added. It displays count of quiz questions.
To be used on HTML elements to display something like `Question 1 out [webform:quiz_elements_count]`
